# Taiyak

[English](../README.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português](README.pt.md) · **Русский**

Браузер, который разбивает исходный код Lean 4 на объявления и показывает рядом с каждым математический перевод на выбранный естественный язык. Он только читает исходный код: собирать Lean не нужно. Название происходит от японского 対訳 (*taiyaku*) — текста, напечатанного рядом с переводом.

**Веб-версия: <https://taiyak.pages.dev/>**

![Impl.lean из демо: код Lean и перевод рядом](screenshot.png)

## Возможности

- Открыть репозиторий Lean 4 по URL на GitHub (в том числе приватный), из ZIP-файла или из папки
- Показывать код Lean и перевод рядом, объявление за объявлением (`def`, `theorem`, `structure`, …). Переводить на японский, английский, китайский (упрощённый или традиционный), корейский, французский, немецкий, испанский, португальский или русский, либо ввести любой другой язык
- Один выбор языка задаёт переводы, интерфейс, глоссарий и пояснения «Спросить Claude». Тексты интерфейса встроены для десяти перечисленных языков (для остальных — английский). Глоссарий встроен на японском и английском; для других языков Claude переводит его при первом выборе языка, и браузер его сохраняет (сначала нажатое слово, остальное — в фоне с индикатором прогресса). В настройках можно отдельно закрепить язык интерфейса
- При первом открытии страница показывается на японском, если браузер предпочитает японский английскому, иначе на английском
- При переводе в качестве контекста отправляются определения из импортируемых файлов, на которые ссылается текущий файл
- Нажатие на идентификатор показывает краткое описание его определения и позволяет перейти к нему. Для символов и тактик вроде `∀`, `omega` и `rcases` есть короткие пояснения
- Длинные доказательства сначала свёрнуты
- Переводы хранятся в браузере. Экспортируйте их и закоммитьте в репозиторий — тогда любой, кто его откроет, прочтёт переводы без ключа API
- Создавать ссылки, которые открывают конкретный файл или объявление

## Использование

### Веб-версия (Cloudflare Pages)

Откройте <https://taiyak.pages.dev/>.

1. Введите URL на GitHub и нажмите «Открыть»
2. В «Настройках» введите ключ API Anthropic, OpenAI, Google или OpenRouter (нужен для перевода). Для приватного репозитория введите также токен GitHub. Кнопка «Создать токен на GitHub» в настройках открывает страницу создания токена на GitHub с уже заполненными правами только на чтение (Contents: read) и сроком 30 дней: выберите нужные репозитории и создайте токен
3. Нажмите «Перевести файл» или «Перевести» у отдельного блока

Если открыть страницу без URL, показывается демо: модель на Lean функции `rb_range_component_beg_len` (нормализация аргументов-диапазонов) из `range.c` в CRuby, со спецификацией, свойствами P1–P4 и моделью исправления. Она взята из закрытого экспериментального репозитория автора `gotoken/cruby-formalized-trial` @74e11c6. Для `Basic`, `Cases`, `Spec`, `Impl`, `Statements` и `Fixed` есть готовые переводы на английский и японский; остальные файлы можно перевести на месте.

### Версия для claude.ai

Если опубликовать `dist/claude-artifact.html` как артефакт claude.ai, каждый зритель будет переводить через собственную учётную запись Claude (ключ API не нужен). Страницы внутри claude.ai не могут обращаться к GitHub, поэтому скачайте репозиторий через «Code → Download ZIP» на GitHub и загрузите его кнопкой «Открыть ZIP».

### Ссылки для обмена

Пока веб-версия показывает репозиторий с GitHub, URL в адресной строке и есть ссылка для обмена. Номера строк в правом верхнем углу каждого блока (`L16–17` и т. п.) копируют ссылку на это объявление.

| Параметр | Значение |
|---|---|
| `repo` | `owner/repo` |
| `ref` | Ветка, тег или коммит (если не указан — ветка по умолчанию) |
| `path` | Открываемый файл |
| `decl` | Имя объявления, к которому прокрутить (для блоков без имени — форма `id=b12`) |
| `lang` | Язык перевода |

Пример: <https://taiyak.pages.dev/?repo=Broyojo/python-formalization&path=lean/PyLean/RangeSlice/Length.lean&decl=slow_isLen&lang=%D0%A0%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%B9>

### Поставка переводов вместе с репозиторием

1. Переведите нужные файлы
2. Через «Настройки» → «Экспорт переводов» получите JSON-файл (экспортируется только открытый репозиторий)
3. Закоммитьте его в целевой репозиторий как `.taiyak/ru.json` (по одному файлу на язык; имя произвольное)

При открытии репозитория `.taiyak/*.json` загружается автоматически. Если вы сами перевели тот же блок, приоритет у вашего перевода. Переводы сопоставляются по языку, уровню подробности и хешу пути файла и текста блока, поэтому, когда код блока меняется, старый перевод больше не используется.

## Ключи и данные

- Ключ API и токен GitHub используются только внутри браузера. В localStorage они сохраняются, только если выбрать «Запомнить в этом браузере». Не сохраняйте их на общем компьютере.
- Страница обращается только к `api.github.com`, `api.anthropic.com`, `api.openai.com`, `generativelanguage.googleapis.com` и `openrouter.ai`. В веб-версии это обеспечивает Content-Security-Policy из `public/_headers`, и браузер отказывается отправлять данные куда-либо ещё. Встроенные скрипты тоже зафиксированы хешем.
- При переводе в выбранный API (Anthropic, OpenAI, Google или OpenRouter) отправляется исходный код Lean файла и определений, на которые он ссылается. Перед переводом закрытого кода проверьте правила своей организации.
- В качестве токена GitHub используйте fine-grained personal access token: выберите только нужные репозитории и права Contents: Read-only.

## Как это работает и ограничения

- Разбиение статическое: учитываются ключевые слова верхнего уровня и то, находится ли текст внутри комментария или строки. Lean не запускается, поэтому информация о типах, раскрытие нотаций и макросов и промежуточные цели тактических доказательств не используются.
- Контекст собирается по импортам на глубину до 3 уровней и до 30 файлов; берутся определения с совпадающими именами. Короткие имена со слишком большим числом определений пропускаются.
- Переводы делает LLM, и в них возможны ошибки. Читайте их, сверяясь с кодом.
- Объявления внутри блоков `mutual` или порождённые макросами могут разбиваться неправильно.

## Разработка

```sh
python3 tools/build.py             # собирает public/ и dist/ из src/ и demo/
node --test "test/*.test.cjs"      # тесты разбиения, сбора контекста и разбора ответов
python3 -m http.server -d public 8000
```

```
src/        template.html, core.js (разбиение и другие части без DOM), app.js (UI),
            i18n.js (языки и тексты интерфейса), glossary.js (глоссарий символов)
demo/       файлы Lean для демо, их переводы на английский и японский, BSDL CRuby
vendor/     KaTeX, JSZip (MIT)
tools/      build.py, исходники переводов демо
test/       тесты node:test
docs/       переводы этого README, снимок экрана
public/     веб-версия (результат сборки; Cloudflare Pages раздаёт этот каталог)
dist/       версия для claude.ai (результат сборки; один файл)
```

После изменения `src/` или `demo/` запустите `tools/build.py` и закоммитьте также `public/` и `dist/`. CI проверяет, что результат сборки соответствует исходникам. Собранные файлы хранятся в репозитории, чтобы то, что раздаётся, можно было прочитать здесь как есть.

## Развёртывание на Cloudflare Pages

1. В панели Cloudflare выберите Workers & Pages → Create → Pages → Connect to Git и укажите этот репозиторий
2. Framework preset: None. Build command: пусто. Build output directory: `public`
3. После сохранения каждый push в `main` развёртывается

Заголовки безопасности из `public/_headers` тоже применяются.
